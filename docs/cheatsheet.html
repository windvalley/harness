命令速查

查阅验证、评审、交付、同步与维护命令。

以下供 Agent、维护者和手工排障时查阅，日常需求直接用自然语言提出。必须由人执行的操作按对应说明处理。

运行 harness help 查看全部命令与参数。

命令用途
init [--dry-run] [--take-over] [--force]接入当前项目，--dry-run 只预览
verify --branch <分支> [--plan] [--no-reuse]验证并写签名证据；--plan 只列计划，--no-reuse 不复用已有结果
attest --branch <分支> --check <检查ID> --command <实际命令> --report <报告>登记已经成功的外部检查，供验证状态与独立评审使用
review --branch <分支>独立评审
status [--branch <分支>]只读汇总还差哪几步才能交付
confirm --branch <分支> [--yes]查看门禁改动摘要；带 --yes 由人记录确认
approve --branch <分支> [--yes --note <原话>]查看方案与授权状态；记录实施授权
merge --branch <分支> [--dry-run]受控合并到主分支（本地交付）
submit --branch <分支>推送核对过的提交并创建或更新 PR/MR（远程交付）
sync [--remote <远程>]把本地主分支快进到远程主分支；--remote 只在首次接入时使用
worktree clean [--yes] [--with-local-files]预览并清理已合并的任务 Worktree；含本机文件的目录需加 --with-local-files 单独同意
doctor安装与接入自检
rules、check --kind ...列出生效规则；手工判定一次调用
golden [--worktree]重放黄金任务
install --local、install --version <版本>、upgrade新机器安装；只把指定版本装进版本目录；升级项目到当前版本
reviewer list、set、remove、prefer、test管理本机评审者：客户端、模型、推理强度、端点与 key
key status、key rotate [--yes]查看证据密钥；轮换由人执行
uninstall [--dry-run] [--purge]解除接入

下一步：配置字段、钩子目录接管、例外上报、卸载等细节见参考手册；版本变化见 CHANGELOG。
