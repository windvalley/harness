# 0.19.1 修复验收

## 范围

修复 043c354 评审确认的上报绑定、Stop 异常隔离与验证复用记录问题。
保持检查定义、复用指纹、gate、extended、observe 和交付授权语义。
仅抽取上报与 Stop 共同的绑定计算，不新增项目配置、依赖图或通用状态机。

## 验收

- 至少两条验签失败的义务含异常 createdAt 时，上报可保存，Stop 不因排序异常跳过整个会话检查。
- 不可信义务不能提供分支版本，已有本地分支使用实际提交，删除分支回退到实际主分支提交。
- 计划中、远端和已删除的合法分支名允许记录通用上报，无法取得可信绑定时明确记录未绑定。
- 调用方不能伪造 HEAD、义务快照或绑定状态，非法分支修订表达式仍被拒绝。
- 无法读取义务与没有义务保持区分，未绑定上报不能使已有或后续创建的任务跳过收尾。
- 单分支计算失败有诊断记录，其他可计算任务仍接受正常收尾检查。
- 无上报时继续检查合并后义务，不因短路优化免除验收。
- 新提交、新义务、技术解除与过期上报继续按现有规则重新核对。
- fail-fast 只跳过需要新执行的检查，有效复用项保留 passed 与 reused，不进入 notExecuted。
- reusedChecks 与账本复用数量符合本轮实际结果，失败 gate 仍拒绝合并。
- 完成定向回归、全量 npm test、文档一致性检查和独立评审。
- 合并推送后发布 v0.19.1 标签与 GitHub Release，保留 v0.19.0。
